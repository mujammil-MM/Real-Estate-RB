# Real-Estate-RB

## Features
- Responsive modern UI
- Property listing sections
- Clean and minimal design
- Mobile-friendly layout
- Fast performance and smooth user experience

- CSS
- JavaScript
- React
- Tailwind CSS

## Purpose
This project was built to practice modern web development, UI/UX design, and AI-assisted coding workflows.
